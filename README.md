My work spans backend architecture, API design, Generative AI integration, RAG pipelines, real-time applications, frontend development, performance optimization, and deployment. ## Engineering in practice

### Performance engineering

One of my recent backend optimization projects involved an OpenLiteSpeed LSCache reverse-proxy layer and Django/PostgreSQL tuning.

<div align="center">

| API throughput | Response latency | Image payload |
|:---:|:---:|:---:|
| **7.6 → 288 RPS** | **4.4 s → 118 ms** | **90%+ reduction** |
| ~**38×** throughput | ~**97%** lower latency | Media optimization |

</div>

Other work included PostgreSQL connection pooling, eliminating N+1 queries with `select_related()` and `prefetch_related()`, atomic F-expression updates, custom CORS middleware for cached responses, and WebP media processing.

<sub>Figures are from the load tests and implementation results documented in my CV; they describe that test environment, not a universal benchmark.</sub>
